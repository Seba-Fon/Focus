# 🧠 Mi App de Productividad

Aplicación web enfocada en mejorar la productividad personal, organización de tareas y hábitos.  
Este proyecto está pensado como una base escalable que puede evolucionar hacia una aplicación completa tipo SaaS.

---

## 🚀 Estructura del Proyecto

A continuación se explica la estructura de carpetas y archivos:


---

## 📂 Descripción de cada parte----------------------------------------------------------------------------------------------


### 🔹 Archivos principales

- **.gitignore**  
  Define qué archivos y carpetas no se deben subir al repositorio (como `node_modules`, `.env`, etc.).

- **README.md**  
  Documentación del proyecto. Explica la estructura, propósito y cómo usarlo.

- **index.html**  
  Punto de entrada de la aplicación. Contiene la estructura base de la interfaz.

---

### 🎨 /css

- **styles.css**  
  Contiene todos los estilos visuales de la aplicación (colores, layout, tipografías, etc.).

---

### 🧠 /js

- **app.js**  
  Archivo principal donde se inicializa la app y se conecta toda la lógica.

- **auth.js**  
  Maneja la autenticación (por ejemplo, login con Google en el futuro).

- **storage.js**  
  Se encarga de guardar y recuperar datos (localStorage o conexión a backend).

---

### 🖼️ /assets

- **/images**  
  Imágenes utilizadas en la app.

- **/icons**  
  Íconos para la interfaz.

---

### 🧩 /components

- **navbar.js**  
  Componentes reutilizables de la interfaz (por ejemplo, barra de navegación).

---

### 📊 /data

- **tasks.json**  
  Datos de prueba (mock data) para simular tareas o información antes de tener backend.

---

### ⚙️ /config

- **config.js**  
  Configuración de la aplicación (API keys, endpoints, etc.).  
  ⚠️ Este archivo puede conectarse con variables de entorno en el futuro.

---

## 🧱 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
